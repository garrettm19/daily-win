# Daily Win mobile

Expo (SDK 57) app for Daily Win. This package currently contains a smoke-test shell only.

## Get started

From this directory:

```bash
npm start
```

Or from the repository root:

```bash
npm --prefix apps/mobile start
```

Scan the QR code with Expo Go on a physical phone.

This project uses [file-based routing](https://docs.expo.dev/router/introduction) in `src/app`.
