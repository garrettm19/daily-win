# Parent pilot feedback template

Product feedback about the **app**. Do not store this as learner evidence.

Copy one block per session.

```
DATE:

Win title:

READY on open?  yes / no

Time to understand activity:  <30 sec  /  30–60 sec  /  >60 sec

Correctly leveled (1–5):

Understood what to do (1–5):

Your job today was useful (1–5):

The challenge felt worthwhile (1–5):

I would use Daily Win again tomorrow (1–5):

Reflection time:  <30 sec  /  30–60 sec  /  >60 sec

Most confusing or annoying thing:

What the parent liked:

What the child appeared to respond to:

Developer issue observed:
```

After each session, also collect:

1. Activity felt correctly leveled
2. I immediately understood what to do
3. Your job today was useful
4. The challenge felt worthwhile
5. I would use Daily Win again tomorrow

Plus: “What was the most annoying or confusing thing?”
