# Device visual QA — V0.4.5

Phone-in-hand checklist for Mason. Educational intelligence is frozen. Do not redesign from this list before reviewing real screenshots.

**Parent Pilot Ready: YES** (software checks). **Real-device visual QA: PENDING MASON REVIEW.**

Capture screenshots of: Home, Mission, Learn, Do, Reflection, Result, Progress, Week, History detail.

For every screenshot answer:

1. What is the first thing my eye sees?
2. Is that the correct thing?
3. Is there one obvious action?
4. Is there too much text?
5. Is anything duplicated?
6. Does this look like a worksheet/classroom?
7. Can progress be understood visually?
8. Does spacing look intentional?
9. Is anything visually heavy/dark?
10. Does it look like one product?

Test at least one smaller iPhone. Flag clipping as **HIGH**. Flag tap/transition lag with no backend wait as **HIGH**.
